# Design System Checklist

Structure adapted from [designsystemchecklist.com](https://www.designsystemchecklist.com/) ([source](https://github.com/ardakaracizmeli/design-system-checklist)). Item names are reproduced as a working checklist; read the full rationale for each item on the site.

Use it to audit a system, not as a gate — a small product does not need every box ticked. Tick an item only when it is documented somewhere a teammate can find it.
